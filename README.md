# 📦 Inventory Management System

A full-stack web application for managing and tracking inventory records using Node.js, Express.js, MongoDB, HTML, CSS, JavaScript, and Bootstrap.

## ✨ Features

- Add new inventory items
- View inventory records
- Update inventory details
- Delete inventory items
- Search and filter inventory
- RESTful API
- MongoDB database
- Responsive web interface

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- HTML5
- CSS3
- JavaScript
- Bootstrap

## 🎯 Project Purpose

This project demonstrates how a full-stack web application can be used to manage inventory data through a RESTful API and MongoDB database.
